description: Start the Angular frontend for the dashboard app
---

Start the frontend application from the workspace.

Steps:
1. Go to the frontend folder.
2. Run npm install if dependencies are not installed yet.
3. Start the Angular dev server with npm start.
4. Open http://localhost:4200 in the browser.

Use these commands in PowerShell:
```powershell
cd frontend
npm install
npm start
```

If port 4200 is already in use, use a different port.
